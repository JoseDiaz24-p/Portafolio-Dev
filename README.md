# 📊 Proyecto 01 — Credit Card Fraud Detection Pipeline

Pipeline ETL desarrollado en **Python y Pandas** para procesar transacciones
financieras, realizar controles de Data Quality, generar variables derivadas
y almacenar los datos procesados en SQLite para su análisis mediante SQL.

### Principales conceptos

- Extracción desde CSV
- Limpieza y validación de datos
- Data Quality
- Detección y tratamiento de duplicados
- Validación de valores numéricos
- Feature Engineering
- Clasificación por rangos de monto
- Persistencia en SQLite
- Vistas SQL analíticas
- Logging
- Ejecución mediante Docker

### Flujo

```text
CSV
 ↓
Extracción
 ↓
Validación y Data Quality
 ↓
Limpieza
 ↓
Transformación
 ↓
Feature Engineering
 ↓
SQLite
 ↓
Vistas SQL
 ↓
Métricas analíticas
```

**Objetivo:** demostrar los fundamentos de construcción de pipelines ETL,
procesamiento de datos, calidad de datos y análisis mediante SQL.

[Ver Proyecto 01 →](./pipelines/01-pipeline-fraude_tarjetas_de_credito/)

# 🤖 Proyecto 03 — Fintech Data Experience & AI Agent

Proyecto que combina **Data Engineering, Data Analytics e integración
experimental con IA**.

El pipeline procesa datos de clientes, genera métricas y segmentos, almacena
la información en SQLite y proporciona una herramienta mediante la cual un
agente puede consultar el perfil de un cliente antes de generar su análisis.

### Principales conceptos

- ETL modular
- Data Quality
- Feature Engineering
- Métricas de clientes
- Segmentación
- SQLite
- SQL Analytics
- SQL Window Functions
- Consultas parametrizadas
- Database Tools
- Gemini API
- Function Calling
- Manejo de errores
- Reintentos ante errores temporales
- Docker
- Docker Compose

### Flujo

```text
CSV
 ↓
ETL
 ↓
Data Quality
 ↓
Feature Engineering
 ↓
SQLite
 ↓
SQL Analytics
 ↓
Database Tool
 ↓
Gemini Function Calling
 ↓
Consulta del perfil

Análisis generado por IA
```

La integración con IA es **experimental y complementaria**. El objetivo
