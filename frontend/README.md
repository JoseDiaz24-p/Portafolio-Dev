# Colección de proyectos Front-End

Colección de proyectos desarrollados con enfoque en interfaces modernas, consumo de APIs, arquitectura de componentes y soluciones corporativas escalables.

---

## 🚀 Proyectos en Producción (Live Demos)

### 1. ROKAMI — Ingeniería y Construcción
* **Demo en vivo:** [https://portafolio-dev-2tdm.vercel.app/](https://portafolio-dev-2tdm.vercel.app/)
* **Stack:** React, Vite, Tailwind CSS, React Router.
* **Descripción:** Landing page corporativa y catálogo técnico interactivo para una empresa del rubro de ingeniería y construcción. Implementa un patrón de navegación *Master-Detail* para la visualización de faenas por especialidad (Salud hospitalaria, Educación, Industria y Retail), visor fotográfico con lightbox y canales de cotización directa integrados con WhatsApp API.

---

### 2. Rick and Morty Explorer
* **Demo en vivo:** [https://rick-and-morty-explorer-lac.vercel.app/](https://rick-and-morty-explorer-lac.vercel.app/)
* **Stack:** React, Vite, Tailwind CSS, REST API.
* **Descripción:** Aplicación web interactiva para exploración y búsqueda de personajes de la serie. Manejo de estado asíncrono, consumo de la API oficial de Rick & Morty, paginación dinámica, filtrado reactivo por nombre/estado/especie y diseño responsive adaptado a múltiples resoluciones.

---

### 3. Antojitos — Pastelería & Cafetería
* **Demo en vivo:** [https://antojitos-pasteleria.vercel.app/](https://antojitos-pasteleria.vercel.app/)
* **Stack:** React, Vite, Tailwind CSS.
* **Descripción:** Plataforma de catálogo comercial y presencia digital para negocio gastronómico. Enfocada en la experiencia de usuario (UX/UI), categorización fluida de productos, diseño mobile-first y llamadas a la acción directas para gestión de pedidos locales.

---

## 🛠️ Tecnologías y Herramientas

* **Frontend:** React, JavaScript (ES6+), Tailwind CSS, HTML5, CSS3.
* **Build Tools & Deploy:** Vite, Git, GitHub, Vercel.
* **Patrones & Arquitectura:** Componentes modulares, Single Page Applications (SPA), consumo de REST APIs, responsive design.
