# 🛸 Rick and Morty Explorer — React & REST API

Aplicación web interactiva desarrollada con **React** y **Vite** para la consulta, filtrado en tiempo real y navegación paginada de la API REST oficial de Rick and Morty.

---

## 🚀 Características Técnicas

* **Consumo Asíncrono de APIs:** Manejo de peticiones HTTP mediante `fetch` con `async/await` y control de excepciones (`try/catch/finally`).
* **Manejo de Estado Complejo:** Control de estados de carga (`loading`), almacenamiento de datos, paginación dinámica (`next`/`prev`) y filtros en tiempo real.
* **Interfaz Responsiva:** Diseño estructurado en cuadrícula (Grid System) con Bootstrap/CSS, tarjetas adaptables y etiquetas dinámicas según el estado del personaje (`Alive`, `Dead`, `unknown`).

---

## 🛠️ Stack Tecnológico

* **Frontend:** React, JavaScript (ES6+), JSX
* **Build Tool:** Vite
* **Estilos:** Bootstrap / CSS3
* **Fuente de Datos:** [The Rick and Morty API](https://rickandmortyapi.com/)
